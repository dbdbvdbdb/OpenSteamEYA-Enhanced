# CS2 本地设置

v0.2.8 新增独立的「CS2 本地设置」页面，原「设置 → CS2 设置同步」功能保留。

## 使用

1. 关闭 CS2，在左侧进入「CS2 本地设置」。选择本机已经存在配置的 Steam 账号。
2. 在画面、音频、游戏 / HUD、准星、鼠标键盘五个标签中调整设置。支持搜索、滑块、数值输入、开关和下拉框。仅列出现有文件中受支持的参数，不用猜测的默认值填充缺失项。
3. 点击「保存并同步云端」。程序先检查游戏是否运行、文件是否被其他进程修改及数值有效性，再备份并保存改动。
4. 用户设置与键位会自动尝试推送到该 SteamID 对应的云端。Steam 必须登录同一账号且启用云服务。失败时明确显示本地保存成功和云端失败，不能据此认为云端已更新。
5. 「撤销修改」丢弃未保存的编辑。「恢复最近备份」恢复最近一次操作前的本地文件，并先备份恢复前状态；该操作明确只恢复本地，不撤回云端数据。

切换账号或重新读取前，如果存在未保存的修改，会询问是否放弃。导航离开页面时保留编辑状态，关闭应用则不保留未保存修改。

## 设置范围

| 分类 | 本版覆盖 |
| --- | --- |
| 画面 | 已有分辨率宽高、垂直同步、MSAA、游戏及菜单帧率上限、全屏 Gamma |
| 音频 | 主音量、游戏 / 语音 / 音乐音量、菜单及回合音乐、十秒警告、切出静音等已有字段 |
| 游戏 / HUD | HUD 缩放、雷达、装备显示、购买菜单、匹配延迟、持枪视角等 |
| 准星 | 新版和经典尺寸、间距、粗细、RGB、不透明度、中心点、T 形、描边、后坐力等已有字段 |
| 鼠标键盘 | 灵敏度、开镜倍率、自动重新开镜；选择按键后覆盖为支持的游戏动作 |

本版是常用参数编辑器，并非游戏全部设置的完整复制。显示模式、刷新率、自动画质检测、高级渲染选项和未核实的参数不改动。准星最终效果受游戏内当前样式影响；修改 RGB 不会自动切换颜色模式。原值超出编辑范围时仍原样显示，不因页面打开而重置。自定义键位命令保持不变，只有明确选择新动作的按键会被覆盖。

## 文件与备份

只操作所选 Steam 安装路径下的 `userdata/<accountId>/730/local/cfg/` 中现有的四种文件：

- `cs2_user_convars_0_slot0.vcfg`
- `cs2_user_keys_0_slot0.vcfg`
- `cs2_machine_convars.vcfg`
- `cs2_video.txt`

保留注释、空白、未知字段、UTF-8/UTF-16 编码以及 `$2` 等实际字段后缀；不改写其他 slot 和 `_lastclouded` 文件。配置结构损坏、重复目标键、路径链接、只读、数值不合法或外部改动会阻止保存。写入过程中会再次检查游戏进程和文件内容；多文件写入失败时尽力回滚，无法回滚的文件会明确报告。

备份存放在 `%AppData%\SteamEYA\cs2-settings-backups/<accountId>/<时间-随机编号>/`，包含本次修改前的文件和 SHA-256 清单。恢复只接受对应账号和受支持文件，校验不一致不写入。此目录独立于账号管理 ZIP 备份，不能用账号管理备份替代 CS2 配置备份。

## 云同步边界

仅将本次改动的用户参数与键位合入现有 `730/remote/cs2_user_convars.vcfg`、`cs2_user_keys.vcfg` 镜像后，通过原 Steamworks 云推送服务提交。保留云镜像中的其他条目，不改动原登录凭据服务。

机器、音频和画面等字段是否可同步取决于实际所在文件：`cs2_machine_convars.vcfg`、`cs2_video.txt` 的修改只保存在本机。缺少或无法安全解析对应云镜像时，本地仍可保存，云端跳过并显示原因。云服务关闭、离线、账号不符或部分失败都不会显示为完全成功。

本地配置、Steam 云及游戏启动加载不是跨系统事务。Steam 或游戏后续可能下载其他设备上的云配置；启动后仍需确认设置是否按预期生效。完整真实云链路需要在自己的测试账号上验收，自动化只使用模拟响应。

## 人工验收

选择测试账号并记录原值，关闭游戏，在五类设置各改一项。检查备份和本地文件后，在 Steam 登录同一账号，确认自动云同步结果，再启动游戏确认实际效果。随后关闭游戏并测试本地备份恢复。另检查 Steam 离线、登录不同账号、云关闭、游戏运行、其他软件同时修改文件时的提示。不要上传真实 userdata、备份或含个人账号的截图。
