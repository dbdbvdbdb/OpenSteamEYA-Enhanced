# v0.2.8 发布验证记录

版本：0.2.8，Windows x64 Native AOT。发布准备日期：2026-10-17。

合并 GitHub 已发布 v0.2.7-beta 的只读配置查看器和本地设置编辑器；分别以「CS2 配置查看」「CS2 本地设置」提供入口。编辑器支持五类常用参数、保存前备份、保存后自动尝试同 SteamID 云推送。原登录凭据、明文密码格式及账号管理业务逻辑保持不变。

## 本地验证

- Native AOT 数据检查：214 项通过。
- 全量 Native AOT WinUI 检查：333 项通过，包含原账号功能、只读查看器与编辑器。复制检查使用短暂占用的有界重试，未修改应用复制服务。
- 正式 Native AOT 包完整性、运行依赖、许可证及测试数据排除检查通过。
- 正式 ZIP 解压后的原生窗口启动、响应和正常退出通过。
- ZIP / 7z SHA-256 在迁移工作目录后再次核对一致。

记录位于 [validation/0.2.8](validation/0.2.8/)，真实软件截图位于 [screenshots/0.2.8](screenshots/0.2.8/)。截图与测试只使用虚构数据；此前本地编辑器开发快照报告不代表已发布 v0.2.7-beta 的功能范围。

## 仍需人工验收

真实游戏加载效果、Steam 云上传以及重新下载后的结果未实机验证。机器和视频文件仅保存本机，云同步需要同账号 Steam、可用云服务与可解析镜像；本地恢复不撤回云端。完整范围见 [CS2 本地设置说明](CS2-LOCAL-SETTINGS.zh-CN.md)。
