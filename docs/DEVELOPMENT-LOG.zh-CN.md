# 开发记录 — 0.2.0

后续追加：2026-10-09 用户要求优化 Windows 发布包，授权安装 C++ 工具链。已完成真正的 Native AOT 发布、运行文件精简、ZIP/7z 高压缩及 AOT 回归检查；报告见 SIZE-OPTIMIZATION.zh-CN.md。以下阶段记录描述首次交付过程，缺少工具链的状态已在后续解决。

开发日期：2026-10-09。本记录描述已完成的本地开发，没有执行远程发布。

## 1. 基础项目与架构审查

读取任务书，克隆 OpenSteamEYA，基线 e68ae7d24ac116826d791902bbaace6076f1936b。先形成 ARCHITECTURE-REVIEW.zh-CN.md，再修改业务代码。参考 Sakiora/SteamAccountManager 的实际版本为表格界面；用户确认按任务书原创实现 WinUI 卡片，因此未复制参考项目的代码和资源。

## 2. 独立管理数据

新增 AccountManagement 库、版本化模型、明文密码存储及 SteamID / 登录账号 / 手动关联。写入使用进程内锁、跨进程独占租约、临时文件和原子替换；发现坏文件时阻止普通覆盖。新增数据位于当前用户 LocalAppData，与原凭证目录分开。

## 3. 导入与导出

实现 TXT、CSV、JSON，预览错误、行号、重复及三种重复处理策略；保留密码特殊字符、引号、反斜杠和换行。实现全部、分组、选中范围及可选备注/身份元数据。解析错误不回显输入密码。

## 4. 原创卡片及原功能接入

增加 WinUI 账号管理页、卡片和紧凑列表、隐私显示、复制、密码显示/隐藏、右键操作及详情。已有账号通过原历史/缓存身份投影到新页面；一键登录和 CS2 查询调用原页面/服务，不使用新增明文密码替代原认证。

## 5. 背景

实现头像多色取色、主题调色、公开 Steam 资料背景、本地背景选择与校验、柔化、裁切/完整/拉伸和回退。异步任务限制并发、缓存并取消过期卡片请求。测试发现 WinRT 临时文件长路径限制，改用 .NET 文件流适配编码；小图片重采样尺寸限制在原图范围内。

## 6. 分组、收藏与排序

实现分组创建/改名/顺序/删除、收藏、搜索、排序及自定义拖动。修复界面重建和拖动时选中状态丢失；合成检查覆盖跨过滤保留选中及分组与文本组合筛选。

## 7. 备份与恢复

实现版本化 ZIP，包含新增账号/密码/分组/备注/收藏/排序/偏好及本地背景。预览和校验数量、版本、重复、路径及大小；先暂存资源再提交数据，失败清理；支持合并与覆盖、有效备份修复损坏管理文件。不打包原 EYA Token 或 Steam 会话。

## 8. 设置、更新与独立维护

设置页接入管理设置、导入、导出和备份入口。保留 upstream，使用 enhancement/account-manager 分支；尚无用户自己的远程地址。禁止增强版自动下载上游安装包。安装脚本改为独立 AppId/目录/文件名；统一便携与安装包的文档、许可打包流程。

## 9. 验证与交付

安装 SDK 后完成 52 项数据层检查及 101 项原生 WinUI 合成界面检查。分别发布带 QA 开关的测试程序和不带 QA 开关的正式自包含程序；QA 使用构建目录合成账号，不读取真实凭证。详细结果、截图和未验证项目见 VALIDATION.zh-CN.md。

当前主机缺少 Native AOT 的 C++ 链接工具，普通 .NET 自包含发布作为本次可运行交付；AOT 路径仍保留。未安装 Inno Setup、未生成安装器、未推送代码或上传发布。原 Steam 在线业务和其他系统/DPI 需要实机验收。
