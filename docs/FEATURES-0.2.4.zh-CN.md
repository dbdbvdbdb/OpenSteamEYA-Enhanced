# OpenSteamEYA Enhanced 0.2.4 — 冷却状态精简

日期：2026-10-09。仅修正用户反馈的冗余状态显示，账号管理、多分组、结果分组、登录、查询、密码、导入导出及备份逻辑保持不变。

| 可靠状态 | 卡片/紧凑列表显示 |
|---|---|
| 无冷却，GCVAC 无标记 | 仅“正常” |
| 有冷却，GCVAC 无标记或未知 | 仅黄色剩余冷却时间 |
| 无冷却或冷却未知，GCVAC 有标记 | 仅红色 GCVAC 标记 |
| 有冷却且 GCVAC 有标记 | 黄色剩余时间和红色 GCVAC 标记 |
| 没有已知异常，但状态未完整获取 | 仅“未知”，不伪称正常 |

倒计时到期自动移除冷却异常；还有 GCVAC 标记时只保留标记，没有其他异常且状态已知时变为“正常”。正常或未知不与实际异常并列。仅显示需要的信息，不再输出“GCVAC：无”。

实现修改位于 SteamEyaWinUI/Pages/AccountCardStatus.cs；AccountManagerGroupsUiChecks.cs 增加单项异常、精简正常、列表和到期检查。其他代码修改仅为版本与交付文档更新。本次没有修改数据模型、存储、分组、凭证或网络服务。

截图使用实际 WinUI RenderTargetBitmap 和隔离合成账号/状态，并非联网查询或生成效果图：[卡片](features-0.2.4/main.png)、[列表](features-0.2.4/list.png)。四个示例依次为双项异常、正常、仅冷却、仅 GCVAC。真实联网仍需用户测试账号验收；当前系统 DPI 为 150%，其他比例只检查导出渲染尺寸。

测试、发布统计与 SHA256 见本报告末尾，原始日志在 test-evidence/features-0.2.4。
