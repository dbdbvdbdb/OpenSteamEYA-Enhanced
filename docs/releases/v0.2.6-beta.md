# OpenSteamEYA Enhanced v0.2.6-beta

Windows x64 Native AOT 预发行版：新增每次启动检查增强版 GitHub 更新。

## 更新内容

- 每次打开程序，后台检查 `dbdbvdbdb/OpenSteamEYA-Enhanced` 的公开 Releases，支持 beta 和正式版本。
- 发现新版时在“关于”显示更新标记，提供版本说明、便携 ZIP 下载入口及官方发布页链接。
- 支持手动重新检查；断网、超时或 GitHub 限流不会阻塞正常使用，也不反复后台重试。
- 修正 beta 子版本、同号正式版的比较，保留当前发布标签，避免重复提示和降级。
- 版本信息直连官方公开 API，不发送 Steam 账号、密码或 Token；下载代理仅影响下载链接及站点延迟检测。
- 本次不修改 Steam 登录、白号／黑号管理、密码存储、导入导出或备份逻辑。

## 使用与升级

ZIP 和 7z 是相同内容的便携程序，任选一个完整解压后运行 `SteamEyaWinUI.exe`，保留全部 DLL、PRI、资源和许可证，无需额外安装 .NET Runtime。

v0.2.5-beta 未启用增强版更新检查，首次升级到本版需手动下载。之后打开程序即可检查未来的新版本；检查更新只提供提示与链接，不自动下载、安装、覆盖文件或重启。

升级前备份数据。管理密码、导出和备份仍以明文保存；隐私模式和密码圆点不是加密。管理备份不包含原 EYA Token、Steam 会话和快速登录缓存。

## 验证与限制

本地 Native AOT 自动化验证：134 项数据与更新逻辑检查、274 项真实 WinUI 检查通过。包含仅检查一次、并发检查去重、beta 比较、断网失败、手动重试及界面状态。

通过相同更新服务的 Native AOT 实现访问真实公开 GitHub API，识别当前线上 v0.2.5-beta 及其 ZIP 附件。界面截图中的 v0.2.7-beta 是隔离测试用虚构响应，并非已发布版本。

GitHub 访问受网络与匿名 API 限流影响，失败时可稍后在“关于”手动重试。无匹配便携 ZIP 时可打开官方发布页。当前读取最近最多 100 条发布记录，忽略草稿与无效版本号。

真实 Steam 登录、Steam Guard 和 CS2 联网查询未在本次新增更新功能测试中执行；其他 Windows 版本及系统 DPI 仍需实机验证。程序未申请维护者 Authenticode 签名。

详见 [更新检查说明](https://github.com/dbdbvdbdb/OpenSteamEYA-Enhanced/blob/v0.2.6-beta/docs/UPDATES.zh-CN.md)；附件校验请以随包 `SHA256SUMS.txt` 为准。
