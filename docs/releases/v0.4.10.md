# OpenSteamEYA Enhanced v0.4.10

Windows x64 Native AOT 便携版。本次是账号页性能版本：减少重复构建、共享主题派生色、合并刷新与计时器。

## 更新内容

- 离开白号管理时释放卡片控件树，避免离页后仍驻留整页可视化树。
- 主题调色板与整卡渐变按「主题 + 深浅」缓存共享，100 张卡片的派生色构建从 200 次降到 0 次；改主色或切主题时统一失效并重建。
- 配置变更通知改为 350 ms 尾随节流并合并，连续改动只重载一次。
- 冷却状态改为页面级单例计时器（1 秒），只驱动存在活冷却的卡片，没有冷却时自动停表。
- 页面切换使用无过渡导航，首帧渲染不再与过渡动画争抢 UI 线程。
- 卡片尺寸变化仅在列数变化或宽度变化超过 2 px 时重排，并合并为一次低优先级回调。
- 卡片背景图解码宽度 720 → 520、缓存上限 24 → 16。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

自 v0.4.5 起可在应用内直接更新：启动时发现新版本会弹窗，点「立即更新」自动下载、校验、重启并替换文件。

## 验证与边界

本地真实 WinUI 自检 367 项全部通过；发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮为性能与稳定性改动，没有改变界面外观与交互，也没有真实 Steam 登录、联网 CS2 查询等实机验证。

## 性能说明

同机同构建、100 个虚构账号下：整页重载从 1049 ms 降到约 644 ms，100 卡调色板构建从 200 次降到 0 次。首屏进入白号管理与切换页面时的内存峰值没有明显变化——卡片仍然在每次进入页面时重建，彻底解决需要按签名复用卡片（已列入后续版本）。
