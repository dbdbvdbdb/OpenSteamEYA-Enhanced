# OpenSteamEYA Enhanced v0.2.7-beta

Windows x64 Native AOT 预发行版：新增 CS2 本地用户设置读取页面。

## 更新内容

- 左侧新增“CS2 本地设置”，选择本机 Steam 账号后，查看键位、视频、游戏、鼠标、准星、音频及其他已保存参数。
- 支持按文件、设置分类筛选，按名称、原始参数、键位或值搜索，并刷新磁盘上的最新配置。
- 常用选项提供简体中文、繁体中文和英文名称，同时保留原始参数和值、来源路径及修改时间。
- 支持 `cs2_user_keys*.vcfg`、`cs2_user_convars*.vcfg`、`cs2_machine_convars*.vcfg` 和 `cs2_video.txt`，读取账号 `730/local/cfg`、`730/remote` 及 `730/remote/cfg` 下的文件。
- 多个配置槽位及本地/云缓存独立展示；单个文件损坏不会影响其他文件。读取不改写配置、不执行绑定命令，也不触发云同步。
- 修复自动化 UI 测试中的搜索事件等待和截图页面识别问题。

## 使用与升级

下载 ZIP 或 7z，完整解压后运行 `SteamEyaWinUI.exe`。两种压缩包内容相同，保留全部 DLL、PRI、Assets、Languages 及许可证文件；无需额外安装 .NET Runtime。

v0.2.6-beta 用户可在“关于”检查更新，或直接从本发布页下载。升级前备份数据并关闭旧程序，将新版解压到新的文件夹。账号管理数据仍保存在原用户目录；管理备份不包含 EYA Token、Steam 会话和快速登录缓存。

管理密码、导出和备份继续以明文保存，隐私模式与密码圆点不加密磁盘文件。

## 验证与限制

本功能及 UI 修复已通过 Windows GitHub Actions 验证：176 项 Native AOT 数据检查、295 项 WinUI 检查，以及生产便携包结构、压缩包和 Native AOT 校验。发布流程会在本版本提交上重新执行相同检查，通过后才生成公开附件。

CS2 配置测试使用隔离合成文件，包含账号隔离、多个 slot、云缓存、损坏文件、搜索和深浅主题截图。真实玩家配置、真实 Steam 登录、Steam Guard、CS2 联网及其他系统 DPI/Windows 版本未在此次发布测试中验证。

显示的是文件中已保存的值，可能与游戏运行中的状态或较新的云端设置不同。不合并不同文件、不补默认值、不推断最终生效配置。自定义 `autoexec.cfg`、启动参数及运行时覆盖不在本次读取范围内。单文件最多 4 MiB、32 层嵌套和 20,000 项参数；不支持的格式会提示读取失败。程序未申请维护者 Authenticode 签名。
