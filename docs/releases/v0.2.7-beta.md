# OpenSteamEYA Enhanced v0.2.7-beta

发布说明草稿；本地交付不代表已创建 GitHub Release。

- 新增独立「CS2 本地设置」页面，以分类标签、设置行、滑块、开关和键位选择器编辑本机现有配置，无需打开游戏。
- 覆盖画面、音频、游戏 / HUD、准星、鼠标键盘五类常用参数，保留原有 CS2 配置同步入口。
- 保存前自动备份，检查运行中的 CS2、外部文件修改、只读与参数范围；提供本地备份恢复。
- 保存后自动尝试推送用户设置与键位到所选 SteamID 的云端，明确区分本地成功、云端失败、部分失败和仅本机项目。
- 保留未知参数、注释、文件编码、版本后缀和未改动的自定义绑定，不调整 Steam 凭据或明文密码逻辑。

限制：仅编辑现有 slot0 配置，不覆盖全部游戏选项；机器与画面配置仅本机保存。云同步需要同账号 Steam 在线、云可用且已有可解析云镜像；真实游戏效果与云端往返仍需测试账号验收。本地恢复不撤回云端。

使用详情见 [CS2 本地设置](../CS2-LOCAL-SETTINGS.zh-CN.md)。下载后完整解压运行；无需 .NET Runtime。账号管理密码和导出仍为明文，请妥善保管数据与备份。

基于 OpenSteamEYA，感谢原作者及依赖维护者；本项目与 Valve、Steam、上游开发者无官方关联。许可与第三方声明随包保留。
