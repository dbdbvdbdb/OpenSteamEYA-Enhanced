# OpenSteamEYA Enhanced v0.4.7

Windows x64 Native AOT 便携版。本次只做一件事：修掉 v0.4.5 / v0.4.6 应用内更新点击「立即更新」后失败的问题。

## 更新内容

- 修复更新失败：点「立即更新」后报 `Cannot be used to terminate a process tree containing the calling process.`，同时独立更新器一直在等主进程退出。原因是旧代码用 `Process.Kill(entireProcessTree: true)` 结束自己——当要终止的进程树包含调用进程本身时，这个 API 必然抛异常。
- 现在的退出方式：先正常关闭主窗口并调用应用退出；另起 1.5 秒兜底，如果 UI 线程没有及时退出就强制结束进程。更新器等到主进程消失后开始替换。
- 更新器 `OSEUpdater.exe` 改为无控制台窗口的程序，覆盖更新时不再弹出黑色命令框。
- 其余功能与 v0.4.6 相同（卡片头像取色背景铺满整卡、导航指示条修复、配装/个性化并入 CS2 配置、登录置首）。

## 升级方式（重要）

v0.4.5 和 v0.4.6 的更新器逻辑有缺陷，**这两个版本无法把自己更新到 v0.4.7**：

1. 下载本页 `OpenSteamEYA-Enhanced-0.4.7-win-x64-aot.zip`（或 7z）；
2. 用 `SHA256SUMS.txt` 校验；
3. 解压覆盖到原安装目录，或解压到新文件夹后替换快捷方式；
4. 从 v0.4.7 开始，之后每次更新都可以在应用内点「立即更新」完成。

## 验证与边界

本地真实 WinUI 自检 366 项全部通过；更新器自测 18 项通过（目标替换、保留用户文件、失败回滚、路径守卫）。发布工作流在本标签上执行锁定还原、数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮没有做真实账号登录与游戏内验证，也没有在只读安装目录下实测回退路径；这些仍以手动替换作为兜底。

## 安全与已知限制

- 管理密码以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 更新包校验使用清单与 GitHub 资产摘要（sha256）；没有 Authenticode 代码签名，Windows SmartScreen 可能提示。
- 覆盖更新会先备份被替换的文件，失败自动回滚；但强杀进程等极端情况仍可能留下半写状态，此时用旧包重新解压即可。
