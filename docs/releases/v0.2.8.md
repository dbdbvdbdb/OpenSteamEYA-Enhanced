# OpenSteamEYA Enhanced v0.2.8

Windows x64 Native AOT 便携版：新增可编辑的 CS2 本地设置，保存前备份，保存后自动尝试同步对应账号的用户配置和键位。

## 更新内容

- 新增「CS2 本地设置」编辑页面，以画面、音频、游戏 / HUD、准星、鼠标键盘五类调整常用参数，无需启动游戏。
- 支持搜索、滑块、数值输入、开关、选项与键位动作选择；未保存修改可撤销，切换账号前会确认。
- 保存前自动备份；阻止游戏运行、外部文件变化、只读、损坏配置和非法数值情况下的写入；提供恢复最近本地备份。
- 保存后自动尝试云推送，核对所选 SteamID；明确区分本地成功、云端失败及部分失败。
- 保留未知字段、注释、编码、版本后缀和未改动的自定义键位。
- 保留 v0.2.7-beta 的多槽位只读能力，入口更名为「CS2 配置查看」；原「设置 → CS2 设置同步」继续保留。
- 合并远程主分支的界面搜索与截图校验修复，自动化测试增加剪贴板短暂占用的有界重试。
- Steam/EYA 登录凭据、明文密码格式及账号管理业务逻辑不变。

## 下载与运行

下载 ZIP 或 7z，核对 SHA256SUMS.txt 后完整解压，运行 SteamEyaWinUI.exe。Windows x64 Native AOT，无需额外安装 .NET Runtime；保留同目录全部 DLL、PRI、Assets、Languages 及许可证。

## 验证

本地 Windows x64 Native AOT 数据测试 214 项、全量 WinUI 检查 333 项通过。全部使用隔离虚构数据；真实游戏与云端验收范围见下方说明。

## 已知限制

- 本版覆盖五类常用参数，不等同于游戏设置菜单全部选项；只编辑已有 slot0 文件，缺失字段不会填入猜测默认值。
- 机器和视频文件只保存本机。云同步需要 Steam 登录所选账号、云服务可用以及已有可解析的云镜像；失败会保留本地修改并提示。
- 本地备份恢复不会撤回云端配置。真实游戏效果、云上传及重新下载仍需测试账号验收；自动化使用虚构配置与模拟云响应。
- 账号管理密码、导出及备份仍为明文，请妥善保管。升级前备份现有数据。
