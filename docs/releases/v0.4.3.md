# OpenSteamEYA Enhanced v0.4.3

Windows x64 Native AOT 便携版。本次加入可自定义的全局主题系统，并为后续界面迁移打好了设计令牌基础。

## 更新内容

- 新增主题系统：只需选择主色与辅助色，其余 29 个语义色自动派生——页面底色、卡片、输入框、对话框、分隔线、三级文字、禁用文字、强调色前景色、成功/警告/错误/信息及其浅色底、卡片横幅渐变。浅色与深色两套分别计算，强调色会自动收敛到与文字对比度达标的亮度。
- 新增主题编辑器页面（设置 → 自定义主题色 → 打开主题编辑器）：6 个快速预设、系统取色器、十六进制输入、冷/暖/中性背景倾向、浅色与深色并排预览，支持应用、取消、恢复默认。编辑过程中整窗实时预览，取消立即还原。
- 主题设置写入配置文件并在下次启动时恢复；主色同时驱动 WinUI 原生强调色，导航指示条、强调按钮与开关会一起变色。
- 全应用颜色统一到语义令牌：旧页面的 WinUI 画刷别名（`CardBackgroundFillColorDefaultBrush`、`TextFillColorPrimaryBrush`、`DividerStrokeColorDefaultBrush` 等）映射到新令牌，配装页的固定深蓝配色与卡片按钮的硬编码白色全部移除。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。主题设置保存在 `%AppData%\SteamEYA`，与账号数据分开。

## 验证与边界

本地真实 WinUI 自检 346 项全部通过，覆盖：生成器确定性与令牌完整性、浅色/深色下的正文与强调色对比度、编辑器页面渲染、应用/取消/恢复默认、设置持久化与还原，以及既有的卡片、列表、筛选、分组、CS2 配置页、更新弹窗检查。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏内结果测试，不能将离线 QA 当作这些功能的实机验证。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也没有使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 部分旧页面尚未重排布局，但配色已跟随主题令牌，切换主题不会出现割裂的颜色。
- 主题只影响界面配色，不改变窗口材质（Mica）与系统动画设置。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
