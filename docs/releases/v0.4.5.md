# OpenSteamEYA Enhanced v0.4.5

Windows x64 Native AOT 便携版。本次加入应用内更新：下载、校验、暂存、退出后由独立程序覆盖，失败可回滚。

## 更新内容

- **应用内更新**：启动检查发现新版本后可一键「立即更新」。更新包下载到 `%LOCALAPPDATA%\SteamEYA\updates\<版本>`，支持断点续传（`.part` + Range），完成后做三重校验——文件大小、`update.json` 里的 SHA-256、GitHub Release 资产自带的 `sha256:` 摘要。
- **独立覆盖程序 `OSEUpdater.exe`**：主程序退出后接管，先做只读检查（目标目录可写、包内没有越界路径），再备份被替换的文件、逐个替换、失败时回滚并重新启动主程序。支持 `--dry-run`、`--verify-only`、`--self-test`，日志写入 `%LOCALAPPDATA%\SteamEYA\logs`。
- **弹窗状态**：发现更新、下载中、已就绪、失败四种状态；「立即更新」直接下载并覆盖，「下载更新」只下载、下次启动提示重启完成安装，「跳过此版本」写入设置后不再提示该版本。
- **数据位置**：`steam_appid.txt` 改写到 `%AppData%\SteamEYA`，覆盖更新不再因安装目录只读而失败。
- **发布流程**：打包时同时生成 `update.json`（版本、标签、下载地址、大小、SHA-256、最低版本、更新说明），随 Release 一同上传，客户端据此校验。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件、`OSEUpdater.exe` 与 `update.json` 同目录结构，否则应用内更新会提示「当前构建不支持」。

支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

## 验证与边界

本地真实 WinUI 自检 353 项全部通过，新增覆盖：更新器自检 18 项（替换、保留既有文件、新增文件、嵌套目录、失败回滚、路径穿越与绝对路径拒绝、版本号清洗）、更新器以 `--self-test` 实际运行且零失败、清单解析与下载地址拼接、跳过版本持久化。

本轮没有在真实网络环境完成一次完整的「下载 → 退出 → 覆盖 → 重启」闭环，也没有覆盖安装目录只读、磁盘写满、杀软拦截等异常路径；这些会在后续版本实测。

**升级说明**：v0.4.4 及更早版本没有内置更新器，从旧版升级到 v0.4.5 仍需手动下载解压；从 v0.4.5 起才能应用内更新到后续版本。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 更新信任链依赖 GitHub Releases 与 `update.json` 的 SHA-256；当前没有代码签名证书（计划后续接入免费或低价的 Authenticode 方案）。请只从本仓库的 Release 页面下载。
- 覆盖程序不对安装目录做所有权检查，只做可写探测；如果安装目录受保护（例如放在 Program Files），会提示改用手动下载。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
