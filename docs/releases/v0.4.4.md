# OpenSteamEYA Enhanced v0.4.4

Windows x64 Native AOT 便携版。本次是常规性能更新，不改变界面布局与数据格式。

## 更新内容

- 账号列表改为一次性快照索引：刷新时只读取一次缓存登录数据并建立 ID 字典，卡片、筛选、搜索与分组匹配都走字典查找，不再为每张卡片各自读一次文件。
- 刷新请求合并：连续触发的刷新只执行最后一次；搜索输入加 200 ms 防抖，不再每敲一个字符就重建整个列表。
- 卡片背景图解码缓存：同一张图片只解码一次，按 480 px 逻辑宽度解码，并保留最近 24 张，减少重复解码与常驻内存。
- 自检新增刷新耗时记录（`INFO perf reload(… cards)`），方便后续版本对比。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。

## 验证与边界

本地真实 WinUI 自检 346 项全部通过，覆盖卡片、列表、筛选、搜索、分组、CS2 配置页、更新弹窗与主题系统；截图覆盖浅色/深色、1180×780 与 1680×980、1.0/1.25/1.5/2.0 缩放。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏内结果测试；性能数据来自本地合成数据（100 个虚构账号），不代表真实账号规模下的绝对耗时。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 本次优化只减少重复读取与重复解码，未改变卡片创建方式；账号数量很大时，首次渲染仍需要创建全部卡片，后续版本会评估虚拟化。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
