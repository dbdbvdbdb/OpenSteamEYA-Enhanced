# OpenSteamEYA Enhanced v0.3.0

Windows x64 Native AOT 便携版。本次精简 CS2 配置入口，并更新项目主页与用户文档。

## 更新内容

- 移除旧“CS2 配置查看”只读页面及导航，保留“CS2 统一配置”用于模板编辑、导入、预览、应用和备份恢复。
- 保留“设置 → CS2 设置同步”独立功能；不删除已有账号配置、模板或备份，不改变云同步规则。
- 清理旧页面专用组件、语言文本和测试入口，增加简体中文、英文、繁体中文切换后的导航回归。
- 更新仓库主页、真实应用截图和中英文说明，补充原 OpenSteamEYA 与增强版的区别；简化更新日志并归档完整技术历史。

原账号管理、Steam/EYA 登录凭据、明文密码格式、CS2 查询、批量导入导出及备份流程保持不变。旧页面专有的多槽位/云缓存只读浏览不再提供，没有新增替代查看页。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。管理数据备份不包含全部 EYA Token、Steam 会话或原快速登录缓存。

## 验证与边界

本地 Native AOT 数据检查 238 项、真实 WinUI QA 319 项通过，均使用虚构数据与隔离配置。移除旧查看页专用测试后，不将已删除检查计入通过数量。v0.3.0 构建重新执行检查并生成真实截图；发布工作流再次运行测试、生产 Native AOT 编译、运行资源/许可证检查和 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏效果测试，不能将离线 QA 当作这些功能的实机验证。

## 安全与已知限制

- 管理密码以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。请勿公开账号、Token 或真实备份。
- 统一配置仅应用本地文件，不自动推送 Steam Cloud。应用前关闭 CS2，云端或其他配置可能覆盖结果；文件写入成功不代表游戏效果已经生效。
- 显示模式、刷新率、Reflex/G-Sync 等部分视频项目仍受原有兼容性限制，具体见[统一配置说明](https://github.com/dbdbvdbdb/OpenSteamEYA-Enhanced/blob/main/docs/CS2-UNIFIED-CONFIG.zh-CN.md)。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
