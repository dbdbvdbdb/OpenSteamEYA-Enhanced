# OpenSteamEYA Enhanced v0.4.9

Windows x64 Native AOT 便携版。本次修复浅色主题下窗口按钮看不清的问题，并把白号管理卡片的头像取色背景调得更清晰。

## 更新内容

- **标题栏按钮**：浅色主题下，最小化 / 最大化 / 关闭三个按钮原本会与标题栏背景同色，几乎看不见。现在显式使用主题令牌给它们上色——前景色跟随主文字色、悬停用次级表面色、按下用更强边框色；切换浅色/深色主题或在主题编辑器里改色时会立即同步。深色主题下保持原有的浅色描边，不会出现反过来的问题。
- **卡片背景**：白号管理卡片「头像取色」背景原先会向中性灰混合得比较多，看起来像糊了一层。现在减少这层混合，背景更接近头像本身的主色，渐变分界也更清楚；浅色主题下的透明度保持不变，文字对比度仍达标。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

自 v0.4.8 起应用内更新已修复，可直接在应用里升级；v0.4.5–0.4.7 的更新器有缺陷，需要手动覆盖一次。

## 验证与边界

本地真实 WinUI 自检 367 项全部通过，其中新增一项针对标题栏按钮：断言三个按钮被设置为显式前景色，且与标题栏背景不同（避免再出现同色不可见）。其余检查覆盖卡片背景、导航、CS2 配置页、更新弹窗与主题系统。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

窗口按钮由系统绘制，自动化截图无法直接截到它们，因此这项以运行期资源断言为准，实际观感请在浅色主题下确认。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也没有使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 头像取色只在本地解码，不上传头像或结果。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
