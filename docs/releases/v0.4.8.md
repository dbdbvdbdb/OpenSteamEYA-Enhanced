# OpenSteamEYA Enhanced v0.4.8

Windows x64 Native AOT 便携版。本次只修应用内更新链路——上一版点「立即更新」会在最后一步失败并回滚。

## 更新内容

- 修复应用内更新最后的「拒绝访问」：更新包里有 `OSEUpdater.exe`，而更新器正从安装目录运行，Windows 不允许覆盖正在运行的 exe。现在更新器先把自己复制到 `%LOCALAPPDATA%\SteamEYA\updates\runner` 再从那里启动，安装目录里的副本不再被占用，可以正常替换；替换逻辑也加了自我保护，遇到正在运行的同名可执行文件会跳过并写日志，而不是整轮失败回滚。
- 更新前清理上次失败留下的 `*.ose-new` 中间文件。
- 更新器不再弹出黑色控制台窗口。
- 应用退出方式改为关闭主窗口 + 1.5 秒兜底退出，不再使用会抛异常的 `Kill(entireProcessTree: true)`。
- 更新器自检从 18 项扩到 22 项：新增「包里含正在运行的更新器时仍应成功」「运行中的文件不得被覆盖」「跳过的文件不计入已应用」「不留中间文件」。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

**重要**：0.4.5 / 0.4.6 / 0.4.7 的应用内更新不可用（更新器试图替换自身），必须先手动下载本版完整包覆盖一次。从 0.4.8 起，之后的版本可以在应用内完成更新。

手动覆盖步骤：退出应用 → 解压新包 → 用新包里的文件覆盖安装目录（保留 `steam_appid.txt` 等用户文件不会受影响，配置在 `%AppData%\SteamEYA`）→ 重新运行 `SteamEyaWinUI.exe`。

## 验证与边界

- 更新器自测 22 项全过（含新增的自我保护用例）。
- 本地真实 WinUI 自检 366 项全过。
- 发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与打包校验。
- 「覆盖安装目录」这一步只在本地用临时目录模拟过，未在你的 `E:\PC\Downloads` 实机上跑完整替换流程；如果仍有失败，日志在 `%LOCALAPPDATA%\SteamEYA\logs\update-*.log`。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML。

## 安全与已知限制

- 管理密码仍以明文存储；隐私模式只遮挡界面。
- 更新包校验：清单 size + sha256 + GitHub 资产 digest；没有代码签名证书，无法做到 Authenticode 级别的来源认证。
- 目标目录只读时仍会失败并回滚，需要手动替换。
