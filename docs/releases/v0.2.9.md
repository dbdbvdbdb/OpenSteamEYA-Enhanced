# OpenSteamEYA Enhanced v0.2.9

Windows x64 Native AOT 便携版：在应用中维护一套独立的 CS2 配置模板，确认后安全应用到本机所有适用 Steam 账号。

## 更新内容

- 「CS2 本地设置」升级为「CS2 统一配置」，无需选择账号或安装 Steam 即可编辑模板；重启应用后保留已保存内容。
- 支持应用默认模板、文件夹导入、账号配置一次性导入、完整原生文件导出，以及模板、批量应用和旧版账号备份恢复。
- 保存与应用分离。应用前预览目标和文件并二次确认；逐账号备份、检查外部修改、原子写入和失败回滚，汇总成功、无需更改、跳过、失败及备份位置。
- 按当前游戏内容核对视频格式 16 的 MSAA/CMAA、阴影、动态阴影、纹理与过滤、着色器、粒子、AO、HDR、FSR、对比度、Gamma、帧率及普通垂直同步；支持向正确节点显式加入缺失的已验证参数。
- 保留分类、搜索、未保存草稿、撤销、即时校验、中文名称及原始参数说明；显示设备与分辨率模式通过 Windows 实际枚举和组合校验。
- 保留未知字段、自定义键位、编码、注释、目标硬件信息及旧版备份。不改动 Steam Token、密码存储或其他游戏数据。
- 原多槽位只读查看、账号管理和独立「设置 → CS2 设置同步」继续保留。

## 升级与运行

下载 ZIP 或 7z，核对随附的 SHA256SUMS.txt 后完整解压，运行 SteamEyaWinUI.exe。无需额外安装 .NET Runtime，保留同目录全部 DLL、PRI、Assets、Languages 和许可证。升级前备份现有应用数据。

首次进入统一页使用应用默认模板，不会自动部署到任何账号。若需沿用账号设置，主动导入一次；以后保存到独立模板。应用账号配置前关闭 CS2。

## 验证

功能分支已通过 Linux 283 项控制台断言、Windows Native AOT 280 项数据检查和 334 项真实 WinUI 检查，覆盖 100 账号、编码、缺失键、冲突、回滚、部分恢复和界面交互。全部使用隔离的合成数据。发行工作流重新执行 Windows 检查、生产 Native AOT 构建和 ZIP/7z 校验；实际执行记录见本标签的 GitHub Actions。

## 已知限制

- 本页只覆盖本地配置，不自动执行 Steam Cloud 推送。Steam Cloud 后续可能重新下载旧配置；本地成功不等于云同步成功。
- 配置依据为 2026-10-15 游戏快照（ClientVersion 2000933 / Patch 1.41.9.1 / video 16），未声称覆盖所有客户端选项。显示模式、宽高比、CS2 显示器编号、刷新率写入、Reflex/G-Sync 和自动硬件等级尚未充分确认，保持不可编辑或只保留导入值。
- 分辨率只在已有整数刷新率且设备支持对应分辨率/刷新率组合时修改。目标视频文件缺失或非格式 16 时跳过并报告，不猜测创建；其他安全文件继续处理。
- 批量部署仅合并已核实参数及标准绑定动作；未知参数和自定义命令保留在模板导出及目标原文件中，不向其他账号传播。启用 FSR 采用保守策略，需先明确关闭 MSAA 和 CMAA。
- 未完成真实 CS2 客户端逐项画面/重启效果、多 GPU/驱动、显示器热插拔、多 DPI、真实 Steam Cloud 回写及断电级崩溃测试。源码核对和自动化检查不代替这些实机验收。
- 账号管理密码、导出和备份仍为明文，请妥善保管。

完整使用方式、参数依据与限制见 [CS2 统一配置说明](../CS2-UNIFIED-CONFIG.zh-CN.md)。
