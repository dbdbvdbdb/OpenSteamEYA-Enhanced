# OpenSteamEYA Enhanced v0.4.2

Windows x64 Native AOT 便携版。本次调整账号卡片背景的来源、新增可自定义的主题配色，并修正「默认分组」的含义。

## 更新内容

- **账号卡片不再按头像取色**：卡片背景改为跟随主题的渐变，或使用 Steam 个人资料背景／本地自定义图片。删除“头像莫奈取色”模式与取色强度设置；旧账号里保存的取色背景会自动回退到跟随主题，不需要手动清理。
- **自定义主题色**：设置页新增「自定义主题色」卡片，最多添加 5 个颜色。第一个颜色作为主色，决定按钮、选中指示与强调色；其余颜色参与账号卡片背景的渐变。支持逐个改色、删除单个颜色与「恢复默认主题色」，保存后立即生效并写入设置。
- **「默认分组」改进**：默认分组现在只列出尚未加入任何分组的账号。账号被分配到分组后会自动从默认分组中移除；分组筛选与账号卡片上的分组名也不再把它算作默认成员。
- 三语语言包补齐上述文案；界面外壳与其余页面的样式未改动。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。

## 验证与边界

本地 Native AOT 数据检查与真实 WinUI QA 全部通过（327 项），覆盖 10/50/100 张卡片、列表视图、隐私模式、深色/浅色主题、1180×780 与 1680×980 两种窗口、1.0/1.25/1.5 缩放，并新增主题色派生、卡片背景回退与默认分组筛选/多分组保存的断言。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，结果见本标签的 GitHub Actions。

主题色目前作用于重绘过的界面（标题栏、导航、白号管理、CS2 配置、设置页的卡片与控件）。尚未迁移的旧页面仍使用系统强调色，等后续版本统一。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或游戏内结果测试。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 自定义图片背景会以文件路径保存在账号数据中，删除原图后卡片回退到主题渐变。
- 部分按键/视频选项仍受既有兼容性限制，详见 [统一配置说明](https://github.com/dbdbvdbdb/OpenSteamEYA-Enhanced/blob/main/docs/CS2-UNIFIED-CONFIG.zh-CN.md)。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现；没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也没有使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。
