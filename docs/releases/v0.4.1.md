# OpenSteamEYA Enhanced v0.4.1

Windows x64 Native AOT 便携版。本次是常规更新：关于页补充原项目信息，CS2 统一配置页改用新界面，并新增启动时的更新提醒。

## 更新内容

- 「关于」页新增「原项目」卡片：说明本项目与上游 [OpenSteamEYA](https://github.com/hvh-software/OpenSteamEYA) 的关系，给出原仓库地址和「打开原项目仓库」按钮。
- 「CS2 统一配置」页按新界面重绘：单行工具栏（模板名 / 导入模板 / 导出模板 / 恢复备份）、胶囊式分类页签、卡片化参数行、底部操作条。字段与行为不变，只是换了外观。
- 修复浅色主题下 CS2 配置页未选中的分类页签仍显示主色的问题：页签配色改由选中状态直接决定，不再受模板视觉状态影响。
- 启动时自动检查更新：发现新版本会弹出提醒，显示当前版本、新版本号与更新记录，可选择「暂不更新」或「立即更新」；立即更新会下载便携包并重启应用完成替换。
- 更新检查失败不会打断启动，错误信息保留在「关于」页；自检模式（`--manager-ui-check`）下跳过启动弹窗。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。

## 验证与边界

本地 Native AOT 数据检查与真实 WinUI QA 全部通过；发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译和 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。CS2 配置页与关于页在浅色/深色主题下都重新截取了真实控件截图做核对。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏内结果测试。「立即更新」使用虚构的发布数据验证了弹窗与下载替换流程，没有对真实 Release 产物做端到端安装验证。

## 安全与隐私

- 启动更新检查只请求本仓库的 GitHub Releases 公共接口，不上报任何账号、Token 或本机信息，也不发送任何凭据。
- 选择「暂不更新」后，本次运行不再弹窗；下次启动会重新检查。
- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 统一配置仅应用本地文件，不自动推送 Steam Cloud；应用前请关闭 CS2。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也未使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。
