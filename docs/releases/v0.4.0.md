# OpenSteamEYA Enhanced v0.4.0

Windows x64 Native AOT 便携版。本次重绘整个界面外壳与白号管理页，账号数据、密码格式、CS2 配置与备份流程均未改动。

## 更新内容

- 新增设计系统 `Themes/PclTheme.xaml`：统一主色 `#1370F3`、页面底色、卡片、分隔线与三级文字色，深浅两套主题；卡片、工具栏、主按钮、次按钮、幽灵按钮、胶囊开关共 11 个样式。
- 重做应用外壳：40 px 自定义标题栏（图标 + 名称 + 版本胶囊）、顶部横向导航（蓝色下划线指示当前页）、页面留白与底部状态条；窗口拖动区域与最小化/关闭行为不变。
- 白号管理页重排：页头大标题与说明、单行工具栏（添加账号 / 搜索 / 分组筛选 / 管理工具）、胶囊式筛选条（排序、视图、隐私模式、批量操作）。
- 账号卡片改为 10 px 圆角的窄横幅样式，取消强制深色，跟随系统主题；新增浅色主题下的选中描边与悬停反馈。
- 顶部导航压缩字号与内边距，`CS2 统一配置` 更名为 `CS2 配置`，1280 宽窗口下不再溢出。
- 其余页面（黑号管理、登录、历史、配装、个性化、设置、关于）暂时沿用旧样式，后续版本逐步迁移。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

升级前备份数据，将新版本解压到新文件夹。

## 验证与边界

本地 Native AOT 数据检查与真实 WinUI QA 全部通过（含 1180×780 与 1680×980 两种窗口、浅色/深色主题、1.0/1.25/1.5 缩放）。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译和 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

界面重绘后同步修正了自检中与卡片样式耦合的部分（卡片像素判定改为与 QA 背景色对比、悬停描边透明度恢复 0.6、紧凑列表补齐冷却状态行），自检覆盖面未缩减。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏内结果测试，不能将离线 QA 当作这些功能的实机验证。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也未使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 统一配置仅应用本地文件，不自动推送 Steam Cloud；应用前请关闭 CS2。
- 其余页面尚未迁移到新样式，切换页面时视觉风格会短暂不一致。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
