# OpenSteamEYA Enhanced v0.2.4-beta

Windows x64 Native AOT 预发布版本，功能基线为 v0.2.4。ZIP 与 7z 为相同的便携程序，任选一种完整解压后运行。

## 本次更新

- v0.2.4 冷却状态只显示实际异常：剩余时间为黄色、GCVAC 标记为红色；无异常显示正常，未获取数据为未知。
- 保留 v0.2.3 多分组、默认分组包含全部账号、CS2 失败/未查询自动分类与成功清理。
- 保留 v0.2.2 逐行批量添加、多选查询、备注显示、右键菜单和双击编辑。
- 保留 v0.2.1 重构账号卡片及 Hover 圆角修复、v0.2.0 独立账号管理、导入导出与备份恢复。
- 开源准备核实依赖许可，将 WinUI 2.2.1 Engineering Preview 替换为允许随应用分发的 2.3.9。补齐文档、锁定依赖、AOT CI、ZIP/7z、校验和及版权门禁。
- 原 Steam 登录凭据管理、EYA 服务、管理密码明文格式与业务源码保持不变。完整历史见 [CHANGELOG.md](https://github.com/dbdbvdbdb/OpenSteamEYA-Enhanced/blob/v0.2.4-beta/CHANGELOG.md)。

## 已验证及已知限制

- WinUI 2.3.9 Native AOT 界面检查 224 项通过，原生数据回归 85 项通过；正式包解压后窗口可启动、响应并正常退出。
- 真实 Steam/EYA 登录、Steam Guard、缓存一键登录、未保存密码账号登录和 CS2 联网查询仍需用户实机验收。页面能打开不等于联网功能已通过。
- 当前测试机实际 DPI 为 150%；100/125/150/200% 截图导出不是各系统 DPI 的完整实机测试。其他 Windows 10/11 系统需验证。
- 管理库备份不含原 Token、Steam 会话和缓存凭据，不能完整迁移登录状态。未配置增强版自动更新源；程序未申请维护者 Authenticode 签名。
- 正式程序由 [GitHub Actions 发布构建](https://github.com/dbdbvdbdb/OpenSteamEYA-Enhanced/actions/runs/38019962559) 生成，源提交为 fd9fb63。原生 PE、运行资源、包内容及两种压缩包完整性检查通过；下载后的附件校验和与 SHA256SUMS.txt 一致。
