# OpenSteamEYA Enhanced v0.2.5-beta

Windows x64 Native AOT 预发行版。本次新增白号／黑号管理，保留原 Steam/EYA 登录、CS2 查询及账号管理功能。

## 本次更新

- “账号管理”更名为“白号管理”，停止启动和刷新时全量同步历史账号。已有管理记录全部保留在白号管理。
- 账密登录新增“同时添加到白号管理”：默认勾选并记忆，认证及历史保存成功后保存账号和本次输入密码；未勾选不新增管理记录。
- 自动／手动模式及账号 Token 导入成功后进入黑号管理；账密验证后自动切到手动模式仍保留账密来源。
- 黑号管理复用历史账号列表，支持搜索、选择、备注、分组及适用的登录和查询操作。
- 跨分类重复弹出记录对照，由用户选择唯一归属；支持手动转移，保留备注、分组、收藏、背景和已有密码。
- 删除时可分别勾选“删除应用内记录”和“删除 Steam 登录缓存”。缓存指应用保存的快速登录缓存，不删除 Steam 客户端安装文件、游戏或正在使用的配置。
- 备份增加分类元数据，兼容旧备份；原管理密码文件格式及核心登录算法不变。

升级前先备份管理数据。旧账号不自动猜测来源，仍在白号管理，可手动转移。新分类与偏好保存在独立 `account-categories.json`；管理备份不含原 EYA Token、Steam 会话及快速登录缓存，不能完整迁移登录状态。

## 验证与已知限制

- 本次附件为本地 Windows 环境生成并验证的 Native AOT 包，非普通自包含 .NET 程序。98 项数据检查、263 项实际 WinUI 检查通过；最终 ZIP 解压启动、窗口响应及正常退出通过。
- 两种压缩包完整性、包内逐文件一致性及许可证保留检查通过。测试使用隔离虚构数据，未打入发布包。
- 真实 Steam/EYA 登录、Steam Guard、实际缓存恢复及 CS2 联网查询仍需用户用测试账号验收；自动化结果不代表这些联网操作已通过。
- 实际系统 DPI 为 150%，其他系统 DPI 和 Windows 版本仍需实机验证。冲突及删除窗口行为已自动验证，弹出层外观仍需人工检查。
- 未配置增强版自动更新源；程序没有维护者 Authenticode 签名。跨文件删除发生磁盘错误时可能部分完成，会提示并允许重试。
- GitHub Actions 状态请查看仓库 Actions 页面；上述附件与测试结果来自已完成的本地构建，不将尚未完成的远端构建计为通过。
