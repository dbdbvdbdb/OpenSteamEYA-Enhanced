# OpenSteamEYA Enhanced v0.4.6

Windows x64 Native AOT 便携版。本次恢复卡片的头像取色背景并铺满整张卡片，修复顶部导航指示条，把「配装」「个性化」并进 CS2 配置页，并把「登录」移到导航最前。

## 更新内容

- **卡片背景**：白号管理卡片重新支持「头像取色（莫奈）」——取头像主色生成三段渐变，铺满整张卡片；显示 Steam 资料背景或本地图片时叠加半透明遮罩，保证账号信息可读。账号编辑里的背景模式恢复四项：跟随默认设置、头像取色（莫奈）、Steam 个人资料背景、本地自定义图片；偏好设置里恢复「头像取色强度」滑杆（0–1）。
- **导航指示条**：修复点击「黑号管理」「白号管理」等页面时下方小蓝条错位的问题。根因是启动时连续两次改写选中项，指示条动画被打断后停在上一个位置；现在只设置一次，指示条稳定停在当前页。
- **CS2 配置整合**：顶部导航的「配装」「个性化」两项移除，改为 CS2 配置页内的一组胶囊页签「统一配置 / 配装 / 个性化」。三个页面仍在同一个导航入口下，切换时各自的加载逻辑照常执行。
- **登录置首**：「登录」成为导航第一项，其后依次是白号管理、黑号管理、历史账号、已缓存账号、CS2 配置。
- **配装页配色**：武器格保留固定深色面板——武器剪影是白色 PNG，放在浅色底上会看不清；分区标题、说明与可选武器按钮改为跟随主题。

## 下载与运行

下载本页 Windows x64 ZIP 或 7z，使用同页 `SHA256SUMS.txt` 校验后完整解压，运行 `SteamEyaWinUI.exe`。不要单独提取 EXE；保留全部运行文件和许可证。支持 Windows 10 1809 及以上 x64，无需额外安装 .NET Runtime。

自 v0.4.5 起可在应用内直接更新：启动时发现新版本会弹窗，点「立即更新」会自动下载、校验、重启并替换文件。从 v0.4.4 及更早升级仍需手动覆盖一次。

## 验证与边界

本地真实 WinUI 自检 366 项全部通过，覆盖：整卡背景铺满与图片/渐变回退、头像取色对话框与强度设置、导航顺序与指示条、CS2 配置页三个页签的切换与页面加载，以及既有的卡片、列表、筛选、分组、CS2 设置、更新弹窗与主题系统检查。发布工作流在本标签上再次执行数据检查、真实 WinUI QA、生产 Native AOT 编译与 ZIP/7z 完整性校验，执行结果见本标签的 GitHub Actions。

本轮没有真实 Steam 登录、联网 CS2 查询、Steam Cloud 或 CS2 游戏内结果测试，不能将离线 QA 当作这些功能的实机验证。

## 界面与素材说明

视觉语言参考了 PCL2 启动器的排版与配色思路，全部在 WinUI 3 中重新实现：没有复制 PCL 的图片、图标、字体或 XAML 代码，界面中也没有使用 PCL 的名称与标识。本项目与 PCL 的开发者没有关联或背书关系。

## 安全与已知限制

- 管理密码仍以明文存储，导出和备份也可能包含密码；隐私模式只遮挡界面，不加密文件。
- 头像取色需要读取头像图片；只在本地解码取色，不上传头像或结果。
- 配装页武器面板在深浅两套主题下都保持深色底，这是为了让白色剪影可见，不是主题失效。
- 生产编译保留原有仅 QA 赋值字段的 CS0649 警告；没有因此停用 AOT 或功能。
