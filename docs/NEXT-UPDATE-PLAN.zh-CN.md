## 移除“CS2 配置查看”页面

目标：删除旧版按账号只读查看配置的独立页面，保留“CS2 统一配置”作为编辑模板与应用配置的入口。

实施范围：

- 移除 `MainWindow.xaml` 中的 `Cs2SettingsNavItem`，以及 `MainWindow.xaml.cs` 中的 `cs2Settings` 页面路由和导航文字。
- 移除旧页面 `Pages/Cs2SettingsPage.xaml`、对应代码和仅用于该页面的检查入口；同步整理 `Cs2ViewerUiChecks`、`Cs2SettingsPageChecks` 与 `ManagerUiChecks` 中的引用。
- 先检查配置读取服务、模型和解析器的全部调用者，仅移除旧页面专用实现。统一配置的账号导入、配置解析、备份恢复和批量应用需要的组件必须保留。
- 保留“设置”中的原 CS2 设置同步功能，不把移除查看页解释为移除同步服务。
- 更新当前使用指南、统一配置说明及相关测试说明；历史更新记录和历史截图保持原版本事实，不改写为新版界面。

数据与行为边界：

- 不删除任何真实账号配置、模板、备份、云文件或登录凭据。
- 不改变 Steam/EYA 登录、明文密码格式、账号分类、CS2 状态查询或云同步规则。
- 旧页面独有的文件来源、槽位等只读浏览能力会随页面退出；本轮不额外制作替代页面。统一配置现有能力不受影响。

验收要求：

1. 导航和应用内跳转不再出现旧查看页面，语言切换后也不会恢复入口。
2. Native AOT 编译成功，旧页面相关引用及测试入口已清理。
3. 统一配置的模板编辑、账号导入、预览、批量应用、备份与恢复回归正常；通过隔离数据检查，不操作真实账号配置。
4. 原独立同步入口、账号管理、登录和查询功能不受影响；未完成真实联网测试时如实标注。
5. 提供真实运行截图，确认导航移除且统一配置页面正常打开；经审核后另行决定版本号和发布。
