# OpenSteamEYA 增强版 0.3.0 — 使用说明

本文适用于 v0.3.0 白号／黑号管理、启动检查更新及 CS2 统一配置版本。Windows x64 便携包采用 Native AOT，无需额外安装 .NET Runtime。WinUI 使用 2.3.9。请阅读并同意 END_USER_TERMS.txt 及 THIRD_PARTY_NOTICES.md 中相应组件的完整条款。

将完整压缩包解压到本地普通文件夹，运行 `SteamEyaWinUI.exe`。不要只复制 EXE；同目录的 WinUI/Windows App SDK DLL、PRI、Assets、Languages 及 Steam API 文件都是程序的一部分。Native AOT 包无需安装 .NET 运行时。未提供安装器。

## 账号管理

白号管理页支持卡片、紧凑列表、搜索、分组、收藏、拖动排序及隐私模式。可手动添加/编辑账号、明文密码、备注和已确认的 SteamID。密码默认遮挡，显示和复制由你操作，不自动清空剪贴板。

点击右上角“添加账号”可选择单个添加或“批量添加账号”。批量输入无需双引号，每行 `steam账号----steam密码`，使用四个半角连字符。空行忽略，账号两端空白去除，密码原样保存；空密码表示未保存密码。格式错误时显示行号，修正后再添加，不会只写入部分合法行。默认跳过重复账号、保留已有密码，也可选择覆盖密码或只补充未保存的密码。

单击卡片选中后，隐私模式后显示“全选”“反选”“取消全选”“查询CS2状态”。全选/反选仅操作搜索、分组筛选后的当前显示账号；筛选隐藏的选择保留，取消全选清除所有选择。CS2 查询按全部已选账号执行，包括暂被筛选隐藏的账号；复用原 EYA 查询凭据，未关联凭据的账号跳过。同一凭据只查询一次，逐个执行并汇总成功、失败和跳过数量。

昵称后显示 `（备注）`；过长时截断，鼠标停留可查看完整内容。卡片右下角三个点已移除，右键卡片打开完整菜单；双击卡片内容打开原账号信息编辑窗口。双击登录、复制等内部按钮不会触发编辑。隐私模式继续隐藏资料并禁止敏感操作。

账号现在可以同时加入多个分组。在编辑窗口或右键“设置账号分组”中勾选多个分组，取消勾选只移除对应归属。“默认分组”始终包含所有账号，即使账号属于其他分组；删除一个分组保留账号及其他分组。按多个分组导出取账号并集，每个账号只导出一次。

批量 CS2 查询结束后，实际报错的账号加入“失败”，没有可用查询凭据而跳过的账号加入“未查询”，其他手动分组保留。成功查询会移除“失败”和“未查询”归属；单账号查询成功也会清除这两个标记。取消后的未处理账号保持原分组，不标为失败。结果分组按名称复用，首次需要时自动创建。

冷却状态只列出实际异常：有剩余冷却显示黄色时间，GCVAC 有标记显示红色标记，二者同时存在才同时显示；没有异常只显示“正常”，不再并列“无标记”等正常项目。未获取可靠状态时继续显示“未知”。可见卡片的剩余时间每秒更新，到期后隐藏该异常、没有其他异常则变为“正常”；离开或移除卡片后停止计时，不会为倒计时额外发起查询。

右键菜单提供复制、登录、CS2 查询、详情、关联、背景和管理操作。新增密码仅用于管理；登录复用原 EYA/缓存凭证，不以明文密码替代 Token。没有保存密码的已有账号仍可用原凭证登录；只有手动账号且没有关联凭证时，需先通过原登录页建立可用登录凭证。昵称不能作为身份关联依据。

删除时分别勾选“删除应用内记录”和“删除 Steam 登录缓存”。前者删除白号、黑号及历史记录（含保存的密码和历史 EYA Token）；后者删除应用保存的快速登录缓存，不改动 Steam 安装目录。未勾选的范围保留。原登录、历史、缓存、配装、个性化及其他功能继续从左侧导航进入。

## 白号与黑号归属

旧版已有管理记录留在白号管理。账密页面默认勾选“同时添加到白号管理”，记忆上次选择；仅在成功验证并保存历史后同步本次密码。未勾选只保存原历史记录。账密获取令牌后自动切到手动模式，不会因此再次归为黑号。

自动／手动登录或查询成功并保存历史，以及历史页的账号／Token 导入，进入黑号管理。历史页批量导入白号进入白号管理。发现跨分类重复时显示两边记录，由你选择归属；取消保留现状。白号右键“转到黑号管理”，黑号勾选账号后“转到白号管理”。

黑号列表复用历史页面；搜索、筛选、选中、查询、详情和 Token 导出沿用原服务。没有 EYA 凭据的转入账号无法直接查询或导出 Token，需补充原凭据；其密码、备注及背景仍在管理库中保留；一键登录可继续使用已有且唯一关联的 Steam 快速登录缓存。

## CS2 配置入口

v0.3.0 已移除旧“CS2 配置查看”只读页面；已发布的 v0.2.9 仍保留该页面。新版使用左侧“CS2 统一配置”编辑模板、从本机账号导入或预览并应用设置。原“设置 → CS2 设置同步”继续作为独立功能保留。页面移除不会删除已有配置、模板或备份，也不改变云同步规则。

## 导入、导出和备份

支持 TXT/CSV/JSON，先预览再选择重复处理策略；导出可选择全部、分组或多选账号。字段及转义规则见 `docs/FORMATS-AND-BACKUP.zh-CN.md`。ZIP 备份包含白号和黑号的管理资料、分类元数据及本地背景；可合并或覆盖恢复，不包含 EYA Token、Steam 会话或原登录缓存。

## 本地文件与背景

管理数据在 `%LocalAppData%\OpenSteamEYA-Enhanced\manager.json`，分类和复选框偏好在同目录的 `account-categories.json`，背景在 `backgrounds`，可再生成缓存在 `cache`。数据、导出及备份中的密码都是明文，请自行保管。不会上传密码。坏文件不会被当作空库覆盖，可通过有效备份恢复。

卡片默认从头像取色，也可选择本地图片或公开 Steam 资料背景；私密、网络失败或不支持的背景会回退。优先账户、在线等状态没有可靠数据时不猜测显示。原程序数据仍在 `%AppData%\SteamEYA`。

增强版从本仓库检查更新，不从上游下载安装或自动覆盖文件。源码、开发记录、测试证据及体积报告随源码交付，运行包仅保留使用/格式说明和许可。根 LICENSE 与 third-party-licenses 保留各自条款。

## 检查更新

每次启动后台检查增强版 GitHub Releases（包含 beta）一次。有新版时“关于”显示红点，可查看更新记录、下载 ZIP 或打开发布页。失败不打断使用，可在“关于”手动重试；不自动下载安装或覆盖文件。版本查询直连官方公开 GitHub API，不附带账号或凭据，下载代理只影响下载链接。升级前备份数据，将新包完整解压到新目录。

## CS2 统一配置（v0.3.0）

左侧“CS2 统一配置”编辑独立持久化模板，无需选择账号。“保存配置”不会修改 Steam 文件；“应用到所有账号”预览目标数量和文件后要求确认，并自动备份、检查游戏运行和冲突，逐账号报告结果。不会推送 Steam Cloud，云端之后可能同步回旧配置。

模板存放在 `%LocalAppData%/OpenSteamEYA-Enhanced/cs2-config`；旧版备份仍保留。支持应用默认模板、文件夹及本机账号一次性导入，导入后不持续绑定来源账号。文件夹导出可供其他电脑导入；“恢复备份”支持模板及账号本地恢复。

完整使用流程、参数依据和未支持项见包内 `docs/CS2-UNIFIED-CONFIG.zh-CN.md`，以及兼容入口 `docs/CS2-LOCAL-SETTINGS.zh-CN.md`。
