## v0.2.4 — 冷却状态显示优化

- 无冷却且 GCVAC 无标记时，仅显示“正常”。
- 只有冷却时，仅显示黄色剩余时间；只有 GCVAC 标记时，仅显示红色标记。
- 两项异常同时存在时，才同时显示两项，避免正常与异常信息混排。
- 冷却到期后自动收起对应异常；未获取可靠数据时继续显示“未知”。
- 精美卡片和紧凑列表同步优化。

## v0.2.3 — 多分组与查询结果分类

- 一个账号可以同时加入多个分组，编辑窗口和右键菜单支持多选分组。
- 默认分组始终包含全部账号，不受其他分组归属影响。
- 删除分组保留账号及其他分组；多分组导出自动去重。
- 批量 CS2 查询报错的账号自动加入“失败”分组；没有可用查询凭据的账号加入“未查询”分组。
- 查询成功后移除“失败”和“未查询”标记，保留其他分组；取消后尚未处理的账号保持原分组。
- 冷却剩余时间使用黄色字体，GCVAC 有标记使用红色字体，支持倒计时刷新。
- 兼容旧版单分组数据和备份，备份恢复支持完整多分组关系。

## v0.2.2 — 批量添加与卡片交互

- 新增批量添加模式：每行输入 `steam账号----steam密码`，无需双引号。
- 支持跳过重复账号、覆盖已有密码或只补充缺失密码，默认保留重复账号的原密码。
- 选中账号后，在隐私模式后显示“全选”“反选”“取消全选”和“查询CS2状态”。
- 全选和反选作用于当前显示的账号，取消全选清除所有选择。
- 昵称后显示括号备注，长内容可通过提示查看。
- 移除卡片右下角三个点按钮，右键打开完整操作菜单，双击卡片内容编辑账号。

## v0.2.1 — 账号卡片界面整改

- 重构账号卡片的背景、头像昵称、登录信息、CS2 状态和底部按钮布局。
- 修复鼠标悬停时出现直角高亮边框的问题，统一卡片、悬停和选中边框圆角。
- 保留可见的键盘焦点提示，优化选中与悬停叠加效果。
- 调整页面搜索、添加账号、筛选及管理工具的布局。
- 改善长昵称、长账号、缺失头像和背景等情况下的显示。

## v0.2.0 — 增强版基础功能与体积优化

- 新增独立账号管理页面，支持账号、密码、昵称、备注、分组和收藏管理。
- 支持精美卡片、紧凑列表、隐私模式、搜索筛选及排序。
- 支持头像取色渐变、Steam 资料背景和自定义图片背景。
- 支持 TXT、CSV、JSON 批量导入导出，以及 ZIP 备份与恢复。
- 自动匹配历史账号和缓存账号，复用原有凭据进行登录和 CS2 查询；身份冲突时由用户确认。
- 改用 Native AOT 发布，无需额外安装 .NET 运行时；清理调试和开发文件，保留必要运行依赖及许可证。
- 程序 ZIP 从约 68.27 MiB 缩小至 27.00 MiB，解压体积从约 169.18 MiB 缩小至 70.05 MiB。

## 当前版本说明

- v0.2.4 提供 Windows x64 Native AOT 便携包：ZIP 约 **27.12 MiB**，7z 约 **16.61 MiB**，解压约 **70.35 MiB**。
- 完整解压后运行 `SteamEyaWinUI.exe`，请保留同目录运行文件。
- 账密登录成功并保存到历史账号后，会自动出现在账号管理中；登录页输入的密码不会自动保存到管理库，可在卡片编辑窗口补充。
- 账号管理中的密码以明文保存在本机，导出和备份也包含明文密码，请自行保管。
- 已完成 224 项界面检查、85 项数据回归及发布包启动检查；真实 Steam 登录和 CS2 联网结果仍需实机验收。
